# Гайд: оверрайды расписания и как увидеть конечное расписание

Гид для работы с `script.js` — сайт `https://kristy98755.github.io/ksma-schedule-23gr/` (GitHub Pages из ветки `main`).

## 1. Как устроен рендер

Данные приходят с прокси (JSON по неделям):

```
https://ksma-schedule.itismynickname9.workers.dev/proxy/75/<понедельник ISO>/get
напр.: https://ksma-schedule.itismynickname9.workers.dev/proxy/75/2026-10-12/get
```

Порядок событий после загрузки страницы (все времена условные):

1. `loadWeek()` для `#CurrWeek` и `#NextWeek` → fetch → рендер DOM.
2. На **каждый** контейнер ставится `setTimeout(..., 300)` → `applyGlobalOverrides()` + `applyOverridesToWeek()` (это **оверрайды**).
3. `onScheduleReady()` (интервал 100мс ждёт уроки в ОБОИХ неделях, затем +50мс) → выполняются **патчи**: `insertLesson` / `removeLesson` / `shiftLessonTime` / `moveLesson` (блок в `script.js`, ищите `insertLesson({`).
4. Через 100мс после патчей оверрайды **применяются повторно** к обеим неделям (страховка).

**Важно: патчи и оверрайды гоняются по времени** — порядок зависит от скорости сети. Отсюда правила ниже (пункт 4).

## 2. Три вида правок

### 2.1. Глобальные замены текста — `applyGlobalOverrides`

Заменяет строки **внутри всего текста** любого места (например, «Большой морфологич.лекц.зал» → «БМЗ»). Ищите объект с заменами в `script.js` (функция `applyGlobalOverrides`).

### 2.2. Оверрайды пар — `overrides` в `script.js`

Объект вида (строка ~310):

```js
const overrides = {
    "Педиатрия|Практика|13.10":"<a href='pediatriya_hnzl.html'>Педиатрия</a><br><a href='pediatriya.srs.html' style='color:#0f0; ...'>СРС</a>",
    "Хирургия (фак.хир.)|Практика":"...",
};
```

**Ключ** = `ТекстПары|Тип|Ключ`, где ключ — в порядке приоритета:

| Форма ключа | Когда срабатывает |
|---|---|
| `Текст\|Тип\|дд.мм` | только в конкретную дату (самый точный) |
| `Текст\|Тип\|weekId` | `CurrWeek` / `NextWeek` |
| `Текст\|Тип` | любая дата |
| `Текст\|дд.мм` | любой тип в дату |
| `Текст` | везде |

- `дд.мм` берётся из `data-date` дня в DOM (напр. `data-date="13.10"`).
- Значение — **innerHTML**: можно вставлять ссылки, `<br>`, инлайн-стили. Зелёная СРС-ссылка: `style='color:#0f0; font-size:14px; font-weight:300; text-decoration:underline; -webkit-text-stroke:0.3px #0f0'`.
- Матч идёт по `textContent` имени пары: `<a href='...'>Педиатрия</a>` на выходе = текст «Педиатрия» (скобки «(фак.терапия)» пропадают — см. гонки).

### 2.3. Патчи (добавить/удалить/сдвинуть/перенести) — внутри `onScheduleReady`

```js
insertLesson({ day:'Понедельник', week:'12.10', time:'12:30-14:45', lessonHTML:`<li class="lesson">...</li>` });

removeLesson({ subject:'Хирургия (фак.хир.)', type:'Практика', day:'Среда', time:'10:10-11:45', week:'cw' });

shiftLessonTime({ subject:'Внутренние болезни', type:'Практика', day:'Вторник',
                  oldTime:'07:00-09:15', newTime:'07:30-09:15', week:'bw' });
```

- `week`: `'cw'` — текущая, `'nw'` — следующая, `'bw'` — обе, `'дд.мм'` — конкретная неделя (патч отработает только в ней, после ухода даты — no-op).
- `day`: русское название, матчится по подстроке в `.schedule__date` («Вторник, 13 октября»).
- `insertLesson` вставляет по времени (позиция = место в отсортированном списке пар дня).

## 3. Чек-лист новой правки

1. Найти точное имя пары в данных (см. прокси) — но помнить про замену оверрайдом.
2. Решить, что это: текст/ссылка → оверрайд; новая/удалённая/сдвинутая пара → патч.
3. Внести правку в `script.js` (оверрайды — в объект `overrides`, патчи — в блок `onScheduleReady`).
4. `node --check script.js` — обязательно (в репо, где лежит файл).
5. `git add script.js && git commit -m "..." && git push`.
6. Дождаться деплоя GitHub Pages (~1-2 мин) и **проверить рендер** (пункт 5).

## 4. Ловушки (проверенные на практике)

1. **Гонка патч ↔ оверрайд.** Патч может выполниться после оверрайдов (или наоборот).
   - Никогда не матчите патчи по **полному** имени с «(фак.терапия)» и т.п. — после оверрайда текст уже заменён. Матчите по короткому имени: `subject:'Внутренние болезни'` (`.includes()` — и до, и после совпадёт).
   - Ссылку **вшивайте прямо в `lessonHTML`** у `insertLesson`, а не полагайтесь на оверрайд: `«<span class='lesson__name'><a href='...'>Предмет</a></span>»`. Тогда ссылка есть всегда, порядок неважен.
   - Оверрайды уже повторно применяются после патчей (+100мс) — это страховка, но не гарантия для патчей.
2. **`shiftLessonTime` портит погоду**, если не сохранять `<br>` — функция это делает сама, не выносите время в отдельный элемент.
3. **Оверрайд с датой `дд.мм` остаётся навсегда** (висит как мёртвый ключ, безвреден).
4. cmd (Windows) ломает кавычки в `node -e` и русский текст — скрипты проверок пишите **в файлы** и запускайте `node file.js`.
5. `inspect.py` в `C:\Users\XAKEP\AppData\Local\Temp\opencode` ломает импорты Python — python-скрипты запускать из другой папки.

## 5. Как увидеть конечное расписание (с учётом всех правок)

Обычный `curl` не поможет — всё делает JS. Нужен headless Chrome:

```bat
"C:\Program Files\Google\Chrome\Application\chrome.exe" --headless=new --disable-gpu --virtual-time-budget=25000 --dump-dom "https://kristy98755.github.io/ksma-schedule-23gr/" > dump.html 2>nul
```

Дальше — разбор `dump.html` (пример парсера ниже, `check_dump.js`). DOM дня выглядит так:

```html
<div class="schedule__day" data-date="13.10" data-iso="2026-10-13">
  <span class="schedule__date">Вторник, 13 октября</span>
  <ul class="schedule__lessons">
    <li class="lesson">
      <div class="lesson__time" data-hour="7">07:30-09:15</div>
      <div class="lesson__params">
        <span class="lesson__name"><a href="internal_aortic_valves.html">Внутренние болезни</a></span>
        ...
```

```js
// check_dump.js — что смотрим на указанной дате
const fs = require('fs');
const html = fs.readFileSync('dump.html', 'utf8');
const re = /data-date="(\d{2}\.\d{2})"/g;
const marks = []; let m;
while ((m = re.exec(html))) marks.push({ date: m[1], i: m.index });
const k = marks.findIndex(x => x.date === process.argv[2] || '13.10');
const start = marks[k].i;
const end = k + 1 < marks.length ? marks[k + 1].i : start + 20000;
const chunk = html.slice(start, end);
for (const li of chunk.match(/<li class="lesson">[\s\S]*?<\/li>/g) || []) {
  const time  = (li.match(/lesson__time"[^>]*>([^<]*)/) || [])[1];
  const name  = (li.match(/lesson__name"[^>]*>([\s\S]*?)<\/span>/) || [])[1];
  console.log(time, '|', name.replace(/<[^>]+>/g, '').trim(),
    '| links:', (li.match(/href="([^"]+)"/g) || []).join(' , '));
}
```

Запуск: `node check_dump.js 13.10`.

**Что проверять всегда:** нужная дата выглядит верно + **соседние даты не сломаны** (оверрайды по коротким ключам бьют шире, чем кажется).

Альтернатива без Chrome — открыть сайт в браузере и смотреть нужный день (результат тот же, просто глазами).

## 8. Мини-FAQ

**Хочу добавить ссылку на конспект к паре** → ключ `Предмет|Тип|дд.мм` в `overrides`, значение `<a href='файл.html'>Предмет</a>`.

**Хочу вторую (зелёную) СРС-ссылку под основной** → через `<br>` + инлайн-стиль (пример в 2.2).

**Пара вообще отсутствует/лишняя** → `insertLesson` / `removeLesson` с указанием дня и недели.

**Время пары неверное** → `shiftLessonTime`, матчить по короткому имени предмета (п. 4.1).

**Не вижу правку на сайте** → (1) `node --check script.js`; (2) закоммичено в `main`?; (3) маркер поллера появился?; (4) headless-дамп по нужной дате.
