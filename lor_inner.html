Клиническая анатомия, физиология внутреннего уха. Методы исследования внутреннего уха

1. Общая характеристика внутреннего уха

Внутреннее ухо (лабиринт) — слуховой и вестибулярный рецепторный аппарат, расположен в пирамиде височной кости.

Два отдела:

  • Костный лабиринт — полости в височной кости
  • Перепончатый лабиринт — повторяет форму костного, заполнен эндолимфой; между стенками — перилимфа
Эндолимфа — высокое содержание K⁺, низкое Na⁺ (по составу близка к внутриклеточной жидкости). Перилимфа — по составу близка к ликвору и внеклеточной жидкости. Нарушение ионного баланса → потеря слуха/вестибулярные нарушения.

Отделы костного лабиринта:

  1. Улитка — слуховой анализатор
  2. Преддверие — маточка и мешочек (отолитовые аппараты)
  3. Полукружные каналы (3 шт.) — кинетические рецепторы

Окна: овальное (к стереоцилиям → вестибулярные рецепторы) и круглое (в барабанную полость — компенсация давления).

2. Клиническая анатомия

2.1 Улитка (слуховой отдел)

  • Закручена на 2,5 оборота вокруг костного стержня (модиолус)
  • Разделена двумя мембранами (Reissner, базилярная) на 3 камеры: лестница преддверия, улитковый проток (эндолимфа), барабанная лестница (перилимфа)
  • В улитковом протоке — кортиев орган (слуховой рецептор)

Кортиев орган: волосковые клетки — наружные (3 ряда, ~12 000) — механические рецепторы; внутренние (1 ряд, ~3 500) — сенсорные. Поверх — текториальная мембрана, в основе — базилярная мембрана. У основания волосковых клеток — афферентные волокна преддверно-улиткового нерва (VIII пара).

Стриа васкулярис — сосудистое сплетение в наружной стенке улиткового протока: продуцирует эндолимфу, поддерживает эндолимфатический потенциал (~+80 мВ), необходимый для трансдукции звука. Дисфункция → болезнь Меньера.

Тонотопия базилярной мембраны: у основания (широкая, жёсткая) → высокие частоты (2000 Гц); у верхушки (узкая, эластичная) → низкие частоты (200 Гц).

2.2 Преддверие и полукружные каналы (вестибулярный отдел)

  • Маточка и мешочек — отолитовые рецепторы (статические): уtpициты с отолитами (карбонат кальция) на гелеотекстурной мембране → реагируют на гравитацию и линейное ускорение
  • 3 полукружных канала — кинетические рецепторы: ампулярный гребешок с купулой → реагируют на угловое ускорение (вращение головы)
  • Все рецепторы — волосковые клетки, иннервируются ветвями VIII нерва (ganglion vestibulare)

Направления полукружных каналов: передний (фронтальный), задний (сагиттальный), латеральный (горизонтальный) — каждая пара работает на одной плоскости, оба уха координированы.

2.3 Слуховой путь

  1. Улитковый нерв (VIII) → ядро улитки (мост)
  2. Трапециевидное тело (частичный перекрёст)
  3. Верхняя оливка → нижние холмики четверохолмия
  4. Наружное коленчатое тело → височная доля, кора (50 % волокон перекрещиваются)

Вестибулярный путь: узел преддверия → верхние и нижние ядра → медиальное продольное пучок → глазодвигательные ядра (вестибуло-окулярный рефлекс) и спинной мозг (вестибуло-спинальный рефлекс).

3. Физиология внутреннего уха

3.1 Слух (слуховой анализатор)

Трансдукция звука: звук → колебания барабанной перепонки → слуховые косточки → овальное окно → волна в перилимфе → колебание базилярной мембраны → изгиб волосковых клеток о текториальную мембрану → деполяризация → выброс нейромедиатора → генерация нервного импульса.

Свойства волосковых клеток: пресинаптическая деполяризация (афферентная активность), тоническая и фазная активность. Наружные волосковые клетки сокращаются → кохлеарный (улитковый) амплификатор → усиление и избирательность по частоте.

Пороги слуха: норма — 0–20 дБ для речевых частот (500–4000 Гц). По частотам: низкие (125–250 Гц), средние (500–2000 Гц), высокие (4000–8000 Гц).

Типы нарушений слуха: тугоухость — кондуктивная (нарушение проведения, ОШ ≥ 30 дБ, костная проводимость сохранена) vs сенсоневральная (поражение волосковых клеток/нерва).

3.2 Вестибулярный анализатор

  • Статическая функция (отолитовые аппараты): оценка положения головы относительно горизонта, вестибуло-спинальные рефлексы (поддержание позы)
  • Динамическая/кинетическая функция (полукружные каналы): восприятие вращения, вестибуло-окулярный рефлекс (компенсаторный нистагм — взор остаётся на фиксированной точке при вращении)
Координация: при вращении — рефлекторный нистагм в сторону поворота. При остановке кресла — постурасторонний нистагм (инерция эндолимфы). Двусторонняя симметричная функция обязательна; асимметрия → ложное ощущение вращения (вертиго).

Вестибулярные рефлексы:

  • Вестибуло-окулярный (ВОР) — вращательный/калибровочный нистагм
  • Вестибуло-спинальный — тонус мышц, равновесие
  • Вестибуло-вегетативный — тошнота, рвота, потливость, тахикардия при избыточной вестибулярной афферентации

4. Методы исследования внутреннего уха

4.1 Исследование слуха

МетодЧто оценивает / суть
Камертоны (Ринне, Вебера, Швабаха, Федеричи)Сравнение воздушной и костной проводимости → различение кондуктивной vs сенсоневральной тугоухости (скрининг, качественный)
Тональная пороговая аудиометрияКоличественный «золотой стандарт»: пороги слуха по частотам, построение аудиограммы (воздух/кость)
Речевая аудиометрияПонимание речи (монолог/списки слов), речевая кривая → дискриминация
Отоакустическая эмиссия (ОАЭ)Активный ответ наружных волосковых клеток (спонтанная/вызванная/тональная) → скрининг новорождённых, оценка статуса наружных волосковых клеток
Слуховые вызванные потенциалы (СВП / ABR)Электрическая активность слухового пути до коры (волокна VIII → мост) → объективная оценка порога, ретрокохлеарные образования (акустическая невринома)
Импедансная тимпанометрияПодвижность барабанной перепонки, целостность слуховых косточек → среднее ухо (вспомогательно)
Камертоны — ключевые пробы:
  • Ринне: воздушная > костной (норма +). Кондуктивная тугоухость — наоборот (−)
  • Вебера: звук к центру → при кондуктивной в больное ухо, при сенсоневральной — в здоровое
  • Швабаха: удлинение костной проводимости — кондуктивная; укорочение — сенсоневральная

4.2 Исследование вестибулярной функции

МетодСуть
Калорическая пробаТёплая/холодная вода (+37 °C / +18 °C) в наружный слуховой проход → конвекция эндолимфы латерального канала → нистагм. Оценивает латеральный полукружный канал, подавление функции уха
Вращательная проба (кресло Барани)Вращение в кресле → постурасторонний нистагм после остановки (инерция эндолимфы). Оценивает все каналы
Электронистагмография (ЭНГ) / видеонистагмография (ВНГ)Регистрация нистагма (электроды/камера) → объективная оценка ВОР, симметрии, спонтанного и позиционного нистагма
Позиционные пробы (Дикса-Холлпайка)Выявление доброкачественного позиционного головокружения (ДПГ) — кристаллы отолитов в каналах
Вестибулярные вызванные потенциалы (VEMP)Ответ саккулярный/увеарный путь на громкий звук (тапотемент) → оценка саккулуса и нижних вестибулярных ядер
СтабилометрияОбъективная оценка устойчивости в позе Ромберга (платформа)

4.3 Инструментальные (визуализация)

  • КТ височных костей — костный лабиринт, перфорация, отосклероз, холестеатома
  • МРТ с тонкими срезами / МР-картирование — перилимфатические свищи, невринома VIII, поражения внутреннего слухового прохода, ишемия лабиринта
Алгоритм при снижении слуха: отоскопия → камертоны → тональная аудиометрия → при асимметрии/одностороннем снижении — СВП + МРТ (исключить акустическую невриному). При головокружении — ВНГ + позиционные пробы.
