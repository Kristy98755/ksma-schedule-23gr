Хирургия (факультетская). 23.09

Тема 1. Облитерирующий эндартериит сосудов нижних конечностей. Клиника, диагностика, тактика лечения

1. Определение и этиология

Облитерирующий эндартериит (ОЭНК, болезнь Бюргера) — облитерирующее поражение дистальных артерий мелкого и среднего калибра ног с преимущественным вовлечением интимы, с тромбозом и вторичным облитерирующим воспалением.

Отличие от облитерирующего атеросклероза:

ПризнакЭндартериитАтеросклероз
ВозрастМолодой (< 40–45 лет)50+ лет
ПолМужчины (курящие)Мужчины/женщины
ПоражениеДистальные, сегментарныеПроксимальные, крупные
СопутствующееТромбангиит (васкулит)Гипертония, дислипидемия, СД
КурениеОбязательный факторФактор риска

Этиология: курение (никотин → спазм + повреждение интимы) — ключевой фактор; холодовые травмы; облитерирующий тромбангиит (болезнь Бюргера); аутоиммунные нарушения.

Патогенез: спазм артерий → повреждение эндотелия → тромбоцитарная агрегация → формирование пристеночного тромба → организация тромба + пролиферация интимы → облитерация просвета → хроническая ишемия конечности.

2. Классификация и клиника

Классификация по стадиям ишемии (Покровский–Лаврентьев):

СтадияКлиника
I — функциональнаяПеремежающаяся хромота (ПХ) на 200–1000 м; ослабление пульса на стопе, зябкость, парестезии
IIа — органическая компенсацияПХ на 200–500 м; похолодание, побледнение, гипотрофия, выпадение волос
IIб — субкомпенсацияПХ < 200 м; стойкая гиперемия при возвышенном положении, отёк, контрактуры
III — декомпенсацияБоли в покое, ишемический отёк, трофические язвы
IV — деструкцияСухая/влажная гангрена пальцев и стопы
Клинические проявления по стадиям:
  • I–II: ПХ, зябкость ног, онемение, выпадение волосяного покрова, нарушение роста ногтей
  • III: боли покоя (усиливаются ночью, при зависании ноги), ишемический отёк, язвы
  • IV: некрозы пальцев → гангрена (сухая при компенсации, влажная при инфицировании)

Пальпаторные признаки: ослабление/отсутствие пульса на артериях стопы (задняя большеберцовая, дорзальная), симптом Оппеля (гиперемия стопы при свисании), симптом Гомбека (бледность при подъёме), ишемическая проба Ишемической лаборатории (покраснение после 2 мин зависания при ТБН < 30 мм рт.ст.).

4. Лечение

Главное условие — полный отказ от курения! Без отказа любые методы неэффективны, прогрессирование неизбежно.

Консервативное:

  • Антиагреганты (аспирин, клопидогрел), антикоагулянты при тромбозе
  • Спазмолитики (дротаверин), вазоактивные (пентоксифиллин)
  • Простагландины (алпростадил/вазапростан) — при III стадии
  • Инфузионная терапия (реополиглюкин), витамины группы B
  • Физиотерапия, ЛФК, баротерапия, гипербарическая оксигенация

Эндоваскулярное: баллонная ангиопластика, стентирование, лазерная реканализация — при коротких окклюзиях.

Хирургическое:

  • Поясничная симпатэктомия — при IIб–III (снимает спазм, улучшает коллатерали)
  • Шунтирующие операции (аорто-бедренное, подключично-бедренное)
  • Тромбэктомия/эндартерэктомия
  • Ампутация — при IV стадии, необратимой гангрене
Тема 2. Варикозная болезнь нижних конечностей. Этиопатогенез. Клиника, диагностика. Тактика лечения. Профилактика

1. Определение и этиопатогенез

Варикозная болезнь (ВБНК) — генетически обусловленная прогрессирующая дилатация подкожных вен с клапанной недостаточностью и хронической венозной недостаточностью (ХВН).

Этиопатогенез (триада):

  1. Дисплазия соединительной ткани (генетика — коллаген III типа) → слабость венозной стенки
  2. Клапанная недостаточность → рефлюкс крови → варикозная трансформация
  3. Венозная гипертензия → растяжение стенки → ещё больший рефлюкс → порочный круг

Факторы риска: женщины (4:1), беременность (прогестерон + растущая матка сдавливает подвздошные вены), ожирение, малоподвижный образ жизни, стоячая работа, тесная обувь/каблуки, запоры, наследственность.

Механизм ХВН: варикозные вены → застой венозной крови → диапедез эритроцитов → гемосидерин → гиперпигментация → липодерматосклероз → трофическая язва.

2. Классификация

Клиническая (стадии):

  • Начальная — тяжесть, отёки, судороги икроножных мышц (без видимых изменений)
  • Компенсации — расширенные подкожные вены, без трофических нарушений
  • Декомпенсации — отёки, гиперпигментация, липодерматосклероз, экзема
  • Язвенная стадия — трофические язвы

Международная CEAP:

КлассПроявление
C0Нет видимых/пальпируемых признаков
C1Телеангиэктазии/ретикулярные вены
C2Варикозно-расширенные вены (> 3 мм)
C3Отёки
C4Кожные изменения (C4a — пигментация/экзема, C4b — липодерматосклероз)
C5Зажившая язва
C6Активная трофическая язва

Плюс причины (E — этиологическая: первичная/вторичная, P — патогенетическая: рефлюкс/обструкция, A — анатомическая: поверхностные/перфорантные/глубокие вены).

3. Клиника и диагностика

Клиника: тяжесть и усталость в ногах (хуже к вечеру), отёки, ночные судороги, зуд кожи, видимые варикозные узлы, кровотечение из узла, трофические нарушения.

Инструментальная диагностика:

МетодЗначение
УЗДС с ЦВКОсновной метод! Локализация рефлюкса, клапанная недостаточность, состояние глубоких вен — перед любой операцией
ПробыПратта (наличие перфорантов), Гаккенбруша (недостаточность ОВ/БВ), Перта
ФлебоманометрияОценка венозного давления, работа клапанов
РеовазографияМикроциркуляция (вспомогательная)
Обязательно перед операцией: УЗДС глубоких вен — исключить тромбоз глубоких вен (ТГВ), иначе операция противопоказана!

4. Лечение

Консервативное (базовое, всем):

  • Компрессионный трикотаж (классы компрессии I–III) — основа терапии
  • Венотоники (детралекс/флебодиа) — симптоматика, тонус вен
  • ЛФК, плавание, душ Шарко; исключение каблуков > 4 см, длительного стояния
  • НПВС/антибиотики — при флебите/экземе

Малоинвазивные вмешательства:

  • Склеротерапия (пенная, UFS) — телеангиэктазии, ретикулярные вены, рецидивы
  • ЭВЛК (эндовенозная лазерная коагуляция) — основной метод лечения ствола БВ
  • РЧА (радиочастотная абляция) — альтернатива ЭВЛК
  • УБАО (ультразвуковая кавернозная коагуляция) — облитерация перфорантных вен

Хирургическое:

  • Кроссэктомия (по Троянову–Тренделенбургу) — перевязка ОВБВ в месте впадения в ГБВ
  • Стриппинг БВ — удаление ствола
  • Комбинированная флебэктомия — кроссэктомия + стриппинг + минифлебэктомия притоков
  • Лечение трофических язв: УЗТ, ПУВА, кожная пластика при неэпителизации

5. Профилактика

  • Компрессионный трикотаж при факторах риска (беременность, наследственность, стоячая работа)
  • Адекватная физическая нагрузка (ходьба, плавание), ЛФК
  • Исключение перегрева (сауна, горячие ванны), солярия, каблуков
  • Нормализация веса, борьба с запорами
  • Длительные перелёты/поездки — компрессия + упражнения для икроножных мышц
  • Своевременное лечение при первых симптомах (тяжесть, отёки, судороги)
