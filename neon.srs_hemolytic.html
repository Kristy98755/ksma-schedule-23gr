Гемолитическая болезнь новорождённых детей. Диагностика и тактика экстренного лечения при выведении новорождённого ребёнка из состояния гипербилирубинемии

Определение

Гемолитическая болезнь новорождённых (ГБН) — заболевание, обусловленное несовместимостью крови матери и плода по эритроцитарным антигенам (чаще по резус-фактору Rh(D) или по группам АВ0), приводящее к избыточному гемолизу эритроцитов плода/новорождённого и развитию гипербилирубинемии.

Классификация

  1. По антигенной несовместимости: Rh-несовместимость, АВ0-несовместимость, несовместимость по редким антигенам.
  2. По клиническим формам: отёчная, желтушная, анемическая.
  3. По тяжести: лёгкая, среднетяжёлая, тяжёлая.

Этиопатогенез

Иммунизация матери антителами к эритроцитарным антигенам плода (при попадании фетальной крови в материнский кровоток). Антитела IgG проникают через плаценту, вызывают гемолиз эритроцитов плода → повышение непрямого билирубина, анемия, гипоксия. При тяжёлых формах — гипопротеинемия, отёки.

Диагностика

  • Анамнез: резус-отрицательная мать, сенсибилизация, предыдущие дети с ГБН, аборты, гемотрансфузии.
  • Лабораторная: группа крови и Rh матери и ребёнка, проба Кумбса (прямая/непрямая), определение титра анти-резус-антител, уровень гемоглобина, гематокрит, ретикулоциты.
  • Билирубин: общий, прямой/непрямой (динамика). Оценка по часам жизни (нормативы по Bhutani, рекомендации).
  • Дополнительно: билирубин сыворотки, прямая проба Кумбса (положительна при Rh-несовместимости), АВО-антитела.
  • Инструментальная: УЗИ плода (отёчная форма — плацентомегалия, гепатоспленомегалия, асцит), кардиотокография.

Тактика экстренного лечения при выведении новорождённого из состояния гипербилирубинемии

  1. Оценка степени тяжести: определить уровень непрямого билирубина по возрасту (часы жизни), наличие факторов риска (недоношенность, инфекция, гипоксия, ацидоз).
  2. Фототерапия: основной метод при непрямой гипербилирубинемии. Интенсивная фототерапия при уровне билирубина, приближающемся к пороговому для обменного переливания.
  3. Обменное переливание крови (ОПК): экстренное показание при тяжёлой гипербилирубинемии (уровень билирубина ≥ критического по часам жизни, билирубиновая энцефалопатия, неэффективность фототерапии). Используют резус-отрицательную одногруппную эритроцитную массу + плазму (или свежезамороженную плазму), объём ~2 ОЦК (160–200 мл/кг).
  4. Поддерживающая терапия: инфузионная терапия под контролем (предотвращение дегидратации при фототерапии), коррекция ацидоза, гипогликемии, гипоксии. Обеспечение термостабильности.
  5. Специфическая терапия: внутривенное введение иммуноглобулина человека нормального (IVIG) — может рассматриваться при Rh/АВ0-ГБН с прогрессирующей гипербилирубинемией перед ОПК (по показаниям, в соответствии с клиническими рекомендациями).
  6. Мониторинг: контроль уровня билирубина каждые 2–4 часа при интенсивной терапии, клиническое наблюдение (симптомы билирубиновой энцефалопатии: вялость, гипертония, опистотонус, судороги), пульсоксиметрия, гемодинамика.

Критерии эффективности и исходы

  • Снижение уровня непрямого билирубина на фоне фототерапии, отсутствие прогрессирования.
  • При ОПК — контроль билирубина через 1–2 часа после процедуры, профилактика осложнений (гипокальциемия, гиперволемия, тромбоцитопения).
  • Профилактика: введение антирезусного иммуноглобулина Rh(-) женщинам в течение 72 часов после родов/аборта при Rh(+) плоде.
